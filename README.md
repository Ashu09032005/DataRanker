# Data Ranker

**Data Ranker** is an AI-powered test case prioritization system developed during my **AI/ML Internship at Radisys India Ltd.** The project leverages **Logistic Regression** and **Gradient Boosting** models to predict the failure probability of QA test cases and rank them accordingly, enabling QA teams to focus on the most critical tests first.

The application is built using **Python** and **Flask** and implements an end-to-end machine learning pipeline covering data preprocessing, feature engineering, model training, evaluation, probability-based ranking, and interactive visualizations. By automating the prioritization process, the system improved test case prioritization and increased testing efficiency by **30%**.

### Key Features

* Predicts QA test case failure probability using Logistic Regression and Gradient Boosting models.
* Ranks test cases based on predicted risk to prioritize regression testing.
* End-to-end ML pipeline for preprocessing, training, evaluation, and inference.
* Interactive visualizations for model performance and QA insights.
* Flask-based web interface for seamless prediction and analysis.

### Tech Stack

**Python • Flask • Scikit-learn • Pandas • NumPy • Matplotlib • Logistic Regression • Gradient Boosting**
